# 2 分钟演示脚本

录制前：在仓库根目录执行 `npm install` 和 `npm start`；如果展示模型聊天，请在页面中配置可用模型。录制时不要展示 API Key、终端中的令牌或 `data/` 内的用户信息。

| 时间 | 画面 | 旁白 |
| --- | --- | --- |
| 0:00–0:15 | 首页与项目标题 | “这是多邻省 AI 学习助手，面向需要理解、练习和对比方言表达的学习者。它不替代语言老师，重点是把模型、词典和练习流程组合成可运行工具。” |
| 0:15–0:35 | 选择粤语或另一种方言，输入一个日常短句 | “用户选择方言和翻译方向后，可以获得翻译、读音或解释。模型提示按方言分别约束注音和输出格式。” |
| 0:35–0:55 | 展示词典、声调或练习功能 | “模型不是唯一信息源：词典、声调、例句和练习通过 MCP 工具调用本地结构化资料。这样结果更可追溯，也能在部分场景下不依赖生成模型。” |
| 0:55–1:15 | 展示学习进度或工具列表/终端 `npm run eval` | “服务端把这些能力注册成工具，并提供可重复评测。这里的九个接口案例覆盖健康检查、工具调用、安全拦截、非法输入和未知路由。” |
| 1:15–1:35 | 输入一条有害请求，展示被拒绝；或展示 `logs/failure_log.md` | “安全上先用硬规则拦截有害、越狱和敏感信息请求，再可选调用 AI 审核。审核模型不可用时系统会明确拒绝，而不是静默放行。” |
| 1:35–1:50 | 打开 `logs/runtime_metrics.json` 或终端 `npm run metrics` | “每个服务请求都有 request ID、路径、状态与耗时日志，但不记录密码、令牌、API Key 或完整输入。指标和失败案例都可复盘。” |
| 1:50–2:00 | README 的未来方向 | “当前限制是没有用人工标注集证明方言生成质量。下一步会补充母语者评测、检索质量和真实用户测试。” |

## 录制后检查

1. 导出为 `demo/demo_video.mp4`，时长控制在 1 分 50 秒到 2 分 10 秒。
2. 在 `demo/screenshots/` 保存至少 3 张截图：首页、核心功能、安全或评测证据。
3. 将视频文件或公开视频链接填入根目录 README 的“演示证据”部分。
