# demo 使用说明

本目录用于存放项目演示素材，支持最终展示与答辩。

- `demo_video.mp4`：核心流程演示视频（课程要求为约 2 分钟）
- `demo_script.md`：可直接录制的 2 分钟讲稿（问题、流程、亮点、失败复盘）
- `screenshots/`：关键页面截图（首页、核心功能、评测或安全证据）

演示结构：

1. 项目价值与目标（15 秒）
2. 在线核心功能演示（40 秒）
3. LLM 工程设计与测试证据（40 秒）
4. 安全边界、失败案例与改进计划（25 秒）

录制前请执行 `npm install`、`npm start`；需要展示模型回复时再配置自己的模型服务和密钥。不要把 API Key、用户口令、令牌或 `data/` 内容录入画面。
