# 最终复盘

## 项目完成了什么

多邻省 AI 学习助手已经形成从浏览器交互、模型提示、结构化词典工具、学习记忆、多 Agent 协作、安全护栏到日志和评测的最小闭环。项目的可复现入口是根目录的 `npm start`、`npm run eval` 和 `npm run metrics`。

## 最重要的工程判断

1. 不把“接入模型”当作工程完成：模型输出必须有 Prompt 约束、工具资料、安全检查与失败路径。
2. 不把本地词典匹配称为完整 RAG：当前是可追溯的结构化检索增强，向量检索仍是后续工作。
3. 不在模型审核不可用时静默放行：当前采用 fail-closed，牺牲可用性以保留安全边界。

## 已验证与尚未验证

评测脚本可验证 MCP 路由、工具注册、确定性工具、安全拦截、非法 JSON 与未知路由；认证脚本可验证注册、登录和令牌访问。它们不能证明方言翻译的语言学准确性，也不能替代真实用户测试。

## 下一步

- 为 AI 审核加入误杀/漏检统计和人工复核流程。
